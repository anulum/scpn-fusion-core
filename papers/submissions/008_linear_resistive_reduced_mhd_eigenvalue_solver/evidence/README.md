# Evidence

`linear_mhd_reduced_model_acceptance.json` is the tracked report
`validation/reports/linear_mhd_reduced_model_acceptance.json`. The copy has
the seven structured public header fields placed first; the scientific payload
is unchanged. The generated `evidence_manifest.json` records the report's
source commit, Git blob identity, SHA-256 digest and role, and binds the five
sources the report records.

`../generate_evidence_manifest.py` rebuilds the copy from the tracked report,
recomputes every number the manuscript quotes, including each criterion's pass
or miss, and fails closed when one prints differently.

The report concerns a slab and a periodic cylinder. It establishes nothing
about toroidal, shaped or nonlinear MHD.
