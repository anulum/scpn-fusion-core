# Build

The historical latency JSON, schema-v3 wiring assessment and fresh-cohort
protocol are custody records and are not regenerated by the normal document
build. To rebuild figures and tables from that frozen evidence, run from this
directory:

```bash
export SOURCE_DATE_EPOCH=1787756047
export FORCE_SOURCE_DATE=1
export TZ=UTC
PYTHONPATH=../../../src ../../../.venv/bin/python figures/generate_figures.py
pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
bibtex manuscript
pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
```

Do not launch the fresh cohort from this review package. Its exact request,
admission gates, endpoints, failure policy, recovery requirements and execution
template are frozen in `evidence/fresh_cohort_protocol.json`. The current status
is `prepared_blocked_not_executable` because the real-kernel initial condition
and calibrated held-out NMPC gates do not pass.

After those gates are independently closed and adequate compute is assigned,
inspect the preregistered request from the repository root:

```bash
jq '.preregistered_request, .pre_run_gates, .execution_template' \
  papers/submissions/002_neuromorphic_vertical_stability_control/evidence/fresh_cohort_protocol.json
```

The result and identity-scoped checkpoints must be written to durable
owner-controlled storage. They enter the manuscript only after full custody,
scientific review and independent reproduction; wiring-only or incomplete
reports are never promoted.

Expected final artefact: `manuscript.pdf`. LaTeX auxiliary files are ignored;
the source, evidence, generated figures and final PDF are intentional records.
