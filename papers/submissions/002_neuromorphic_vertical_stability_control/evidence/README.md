# Evidence

- `historical_controller_latency.json` preserves every value from the legacy
  tracked result and binds it to the original Git blob and SHA-256. It also
  records the old source identity, methodology defects, unknown invocation
  count and strict non-comparability boundary.
- `schema_v3_wiring_assessment.json` is an exact summary of the current tracked
  one-episode wiring report. It records the common scenario/contract identities,
  all lane statuses and policy-only latencies, the time-zero disruption, and
  the unavailable NMPC-JAX lane. It is not promotion evidence.
- `fresh_cohort_protocol.json` pre-registers the 200-episode real-kernel cohort,
  its complete seven-lane registry, endpoints, pairing, failure handling,
  recovery, independent reproduction and exact blockers. Its status remains
  `prepared_blocked_not_executable`; no cohort has been started.
- `controller_latency_table.tex` and `schema_v3_wiring_table.tex` are generated
  from those two frozen evidence records.
- `vertical_stability_reduced_order.json` is generated by the vertical-response
  figure script and records the plant contract and controller outcomes.
- `evidence_manifest.json` is generated last. It verifies the live schema-v3
  report and source/config hashes, rejects any rehabilitation of the invalidated
  legacy lane, verifies the exact blocker inventory, and binds every paper-local
  evidence artefact by SHA-256.

None of these files contains a hardware or plasma-discharge measurement.
