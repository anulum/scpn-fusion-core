# Evidence

`runaway_kinetic_rust_benchmark.json` is the tracked report
`validation/reports/runaway_kinetic_rust_benchmark.json`. The copy has the
seven structured public header fields placed first; the scientific payload is
unchanged. The generated `evidence_manifest.json` records the report's source
commit, Git blob identity, SHA-256 digest and role, and binds the twelve
sources the report records.

`../generate_evidence_manifest.py` rebuilds the copy from the tracked report,
recomputes every number the manuscript quotes, and fails closed when one
prints differently.

The report concerns one synthetic parity case and one host. It establishes no
DREAM equivalence, no physical runaway result and no portable speed-up.
