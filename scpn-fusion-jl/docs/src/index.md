# SCPNFusionSolvers.jl

`SCPNFusionSolvers` contains the native Julia fixed-boundary
Grad-Shafranov reference solver and flux-derived current diagnostics. Its
numerical outputs are implementation/reference results, not facility-grade
experimental validation.

The [API reference](api.md) is generated from source docstrings. Its build
fails on missing exported documentation, broken references, and doctest
errors.
